# Security and safety

Please do not publish credentials, private purchase records, unredacted user
files, or vendor SDK installers in issues or pull requests. Report a suspected
secret leak privately to the repository owner and rotate the credential.

This hardware contains high-voltage transmit circuitry and stored energy. A
software or CAD change that can alter transmit amplitude, bias, timing,
connector pinout, or power sequencing requires an engineering review and a
current-limited bench test before release. This archive is research hardware,
not a medical device.
