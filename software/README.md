# Official GUI and host-software entry points

The host applications are kept on the same product-line split as the
hardware and firmware. Use the matching entry document before connecting a
board:

- [WULPUS v1 GUI entry](wulpus/GUI_ENTRY.md) for the four-board v1 system.
- [WULPUS PRO GUI entry](wulpus-pro/GUI_ENTRY.md) for the integrated PRO
  acquisition board and the polyCMUT/Wi-Fi workflow.

The notebooks and the `wulpus/` Python packages in these directories are the
official upstream debug interfaces. They are preserved without source edits;
the entry documents only add reproducible paths, environment commands, and
hardware-safety checks.
