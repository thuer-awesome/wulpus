# WULPUS v1 nRF52 programmer PCB

Use the source and JLCPCB package here for the nRF52 programming adapter. The
package has two BOM groups and two designators; only one placement is SMT.
`S_NRDC1` is a through-hole/manual-solder connector and is intentionally not in
the SMT placement step.
