# WULPUS v1 MSP430 programmer PCB

Use the source and JLCPCB package here for the MSP430 programming adapter. The
package has two BOM groups and two designators; only one placement is SMT.
`J_OLMX1` is a through-hole/manual-solder connector and is intentionally not in
the SMT placement step. Follow the pinout in the assembly drawing before
connecting an MSP-FET.
