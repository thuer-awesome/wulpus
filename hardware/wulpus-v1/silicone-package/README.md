# WULPUS v1 silicone package

The source folder contains the official mold STL files and the upstream
instructions. Use the `*_fdm.stl` files for fused-deposition printed molds and
the `*_resin.stl` files for resin/SLA molds. `wulpus_silicone_cap_mold.stl` is
the cap mold. Confirm scale and shrink compensation with a printed test part
before casting.
