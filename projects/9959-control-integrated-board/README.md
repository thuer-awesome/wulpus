# 9959 Control Integrated Board (separate project)

This folder preserves the independent EasyEDA handover delivered alongside the
WULPUS work. It is **not** one of the WULPUS v1 or WULPUS PRO boards and must not
be included in a WULPUS manufacturing order.

The `.eprj2` source and its BOM audit outputs are retained for traceability. The
internal workbook-inspection logs were intentionally omitted; the human-readable
CSV/XLSX/Markdown and preview images remain under `outputs/`.
