# Reference

Reference material is non-runtime evidence used to understand and audit the
design:

- [`datasheets`](datasheets): vendor document index, URLs, and recorded hashes;
  vendor PDFs are not redistributed here.
- [`source-repository-maps`](source-repository-maps): selected upstream
  READMEs and metadata used during integration.

The authoritative schematics, PCB files, BOMs, and CPLs remain in the matching
board directory under [`hardware/`](../hardware/).
