## 厂家执行规则

1. 先按本清单的官方 MPN、封装、面别、X/Y、Rotation 补齐全部 25 个实际贴装位号。
2. 决策等级 A 可直接按原型号下单；B 只能在工程确认候选料的 datasheet、DC-bias/电流/功率/阻值误差、焊盘和首件测试后替换；C 禁止未经批准替换。
3. 禁止用 HV2708 替代 HV2707；禁止用普通天线替代 NN03-320；禁止用 FPF2106 直接替代 XC8102；禁止把 L3 的 10uH、±20%、1Ω 候选当成等料。
4. 补贴完成后执行 AOI、焊点/共面度检查，并分级上电检查 3V3、5V、15V/HV；对 Y20 追加 nRF 射频、晶振起振、I2C 默认状态、RX 带宽和连接器配对检查。
