# WULPUS PRO production files

WULPUS PRO has a different integrated board architecture. Use the PRO
acquisition development board package and, if needed, the polyCMUT adapter;
do not combine them with the v1 Acquisition/HV BOMs. The source snapshot is
`pulp-bio/wulpus-pro` `dev` at
`d49cf62a53e260d7670d7375b2f6ca3aad627ea7`.

Before ordering the main board, read both errata files in `docs/errata/` and
the copy in the board's `03_Reference/`. The `pzt_hia_no_bias` variant and the
JLC061011_2116A stackup are the reference production choices.
