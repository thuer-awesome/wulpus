# WULPUS Pro 主板 ERRATA 中文核对

本文件只解释官方 docs/ERRATA.MD。Gerber、BOM 和 CPL 保持官方 pzt_hia_no_bias 版本，没有替用户擅自改板或改料。

## 下单前必须决定

1. U16 输入电容
   - 官方指出 U16 输入端至少需要 1 uF，但 v1.0.0 没有放置。
   - 当前官方 BOM/P&P 没有一个可直接对应的新增电容位号，不能在嘉立创自动贴片时凭空添加。
   - 应由硬件工程师确认飞线/补焊位置、额定电压、封装和布局后再生产。

2. C12 源文件不一致
   - ERRATA 说现有 WULPUS PRO 1 实物在 C12 装 220 pF，以适配 5 MHz Vermon 换能器，而不是 1 nF。
   - 但本提交的官方 BOM_clean.xlsx、官方 variant BOM 和官方 Pick Place 中均没有 C12。
   - 因此本下单包没有把 C12 加入嘉立创 BOM/CPL。必须根据实际换能器和原理图由设计方确认是否补装 220 pF。

3. R23 / RGND 高压偏置返修
   - 官方 BOM/CPL 原样包含 R23。
   - 官方 ERRATA 的现版 workaround 是移除 R23，再用导线把 RGND 接到 +HV。
   - 这会影响高压偏置稳定性，只能在断电、放电并由熟悉高压模拟前端的人员评审后实施。

4. PJ1 编程接口镜像
   - PJ1 相对旧 WULPUS v1.2.2 的 MSP430 编程接口是对称镜像。
   - 旧版 MSP430 转接板不能直接使用；必须使用能对称换线的 FPC/转接线，并逐针通断核对。

5. J1/J2 高度
   - 官方 BOM 使用 DF40C-40DS-0.4V(51)，堆叠高度 1.5 mm。
   - 该高度约等于两连接器之间 HV2707 的高度。官方建议改用更高型号留机械余量。
   - 不得只按外观替代；要同时核对 DF40 配对端、针数、0.4 mm 间距、板端公母和总堆叠高度。

6. AD8338 OFFSN
   - 官方建议 OFFSN 接电容，增加高通滤波以减轻 MSP430 接收伪影。
   - 这是后续设计改进建议，不是当前 Gerber/BOM 已实现功能。
