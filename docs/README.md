# Documentation

This directory contains integration and manufacturing documentation that is
separate from the unmodified upstream source snapshots:

- [`board-index`](board-index): board-to-source and board-to-manufacturing map.
- [`manufacturing`](manufacturing): JLCPCB packages, factory checklists, and
  the Y19/Y20 missing-component audit.
- [`errata`](errata): known PRO assembly and bring-up corrections.
- [`manuals`](manuals): upstream user manuals and images.
- [`provenance`](provenance): package notes and source-archive metadata.

Start with the root README, then select exactly one board in the board index.
