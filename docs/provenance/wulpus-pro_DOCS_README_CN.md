# 文档说明

当前固定的 WULPUS Pro 提交根目录没有 README 所写的 docs/ 目录，因此 Pro 专用用户手册并未随仓库发布。

本包已把两块 PCB 自带的原理图、主板装配图和 ERRATA 分别放在嘉立创下单包的 03_Reference/ 中。

Pro README 要求装配和 GUI 基础流程参考旧版 WULPUS v1.2.2 用户手册。为了便于复刻，本包从本机已整理的官方旧版仓库快照复制了一份到 legacy_wulpus_v1_2_2_reference/。它是旧版参考资料，不代表 Pro 主板机械接口完全兼容；PJ1 镜像问题必须以 Pro ERRATA 为准。
