# Analysis archive

Only completed, reviewable analysis is included here. The selected study notes,
reverse-engineering report source/assets, and rendered PDFs support design
review; they are not replacements for the official Altium source or factory
BOM/CPL. Portable CAD runtimes and temporary conversion output remain excluded
as documented in [`provenance/EXCLUDED_ARTIFACTS.md`](../provenance/EXCLUDED_ARTIFACTS.md).
